# Fase 5 — Dashboard, Penjelasan & Instrumen Pengujian

**Jalur:** A · **Target:** minggu 9 · **Status:** ⬜ Belum mulai

## Tujuan
Menyempurnakan dashboard, penjelasan keputusan, dan instrumen pengukuran efisiensi/efektivitas
(sebagian sudah dibangun sebagai dasar di Fase 0 — di sini dimatangkan & dipoles).

## Deliverable / Checklist
- [ ] Dashboard penuh (FR-22…FR-24): daftar real-time, detail lengkap tiap tier + alasan, ranking terurut
- [ ] Generator alasan berbasis aturan (OI-07) — perkaya dari kategori fuzzy + skor tiap tier
- [ ] Log durasi eksekusi (FR-25) + perekaman verifikasi manual (FR-26) — verifikasi lengkap
- [ ] Instrumen ukur (Bab 9.2/9.3): efisiensi = min(5s/aktual,1)×100% + % permintaan ≤5 dtk
- [ ] Efektivitas vs verifikasi manual (target ≥85%, OI-18) — halaman/laporan khusus
- [ ] Poles UI profesional (Bootstrap 5), responsif desktop & smartphone (NFR-03)

## Exit criteria
Petugas dapat meninjau seluruh hasil + alasan, dashboard real-time, dan metrik efisiensi/efektivitas
tampil dan terhitung otomatis dari `log_pengujian`.

## Catatan & artefak
Taruh di folder ini: tangkapan layar dashboard final, catatan uji usability awal, desain laporan metrik.
